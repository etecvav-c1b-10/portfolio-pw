Modelos de Serviços em Nuvem

A arquitetura em nuvem é dividida em três pilares principais conforme a camada de gerenciamento.

IaaS

Infraestrutura como Serviço

Aluguel de infraestrutura de TI (servidores virtuais, rede, armazenamento) onde você gerencia o sistema operacional e as aplicações.

Ex: AWS EC2, Azure VMs

PaaS

Plataforma como Serviço

Ambiente completo para desenvolvimento e implantação de softwares, eliminando a preocupação com o gerenciamento de servidores.

Ex: Heroku, Google App Engine

SaaS

Software como Serviço

Aplicações prontas para uso direto pelo navegador web, sem necessidade de instalação local ou manutenção técnica.

Ex: Google Workspace, Microsoft 365
